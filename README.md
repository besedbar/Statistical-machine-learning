# Statistical Machine Learning

This repository contains Python assignments from a Statistical Machine Learning course at Czech Technical University.

The projects cover selected topics in statistical learning, model evaluation, neural networks, kernel methods, ensemble learning, maximum likelihood estimation and expectation-maximization.

---

## Repository Content

| Folder | Topic |
|---|---|
| `01_confidence_interval` | Confidence intervals and uncertainty estimation |
| `02_generalization_bound` | Generalization bounds and model performance estimation |
| `03_neural_network` | Basic neural network implementation and training |
| `04_kernel_percepton` | Kernel perceptron and kernel-based classification |
| `05_ensembling_template` | Ensemble learning methods |
| `06_maximum_likelihood` | Maximum likelihood estimation |
| `07_em_image_reconstruction` | Expectation-maximization for image reconstruction |
